# METAL

**METAL** — a journal finder to (1) match academic journals to a research topic and (2) check any journal's percentile / quartile, built over a SCImago Journal Rank (SJR) snapshot of ~18,000 journals across 27 subject areas.

*Created by Nae for ease of academic process — a neuromanagement effort.*

**Live site:** `https://<your-username>.github.io/<repo-name>/`

Everything runs client-side in one `index.html` (data embedded). The only network call is the optional DOI lookup to Crossref. Data derived from the open SJR-Journal-Ranking dataset (SCImago / Scopus), ~2020 snapshot; treat percentiles as a guide, not an official current figure.
